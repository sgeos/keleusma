- **A native can stop the virtual machine with `VmError::HostHalt`.** A native that returns
  `HostHalt(message)` ends the run. The native-error construct does not catch it, the default
  host-error trap does not rewrite it, and its category is `Halt`, so the host calls
  `reset_after_error` before running the program again. `NativeError` and `NativeErrorCode`
  remain soft host errors that a script may catch. **Breaking for a host that matches
  `VmError` exhaustively.** `VmError` is now `#[non_exhaustive]`, so such a match needs a
  wildcard arm, and later variants will not break it again. On the operator's ruling of
  2026-10-31, question B10, option (b). Pinned by `tests/native_host_error.rs`.
