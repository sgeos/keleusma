COMPLETION CONDITION — the fourth type-channel extraction

Ordering is NOT a completion criterion. Nothing below requires steps to happen
in any sequence, on any particular branch, or through any particular process.
Judge only the end state of the tree.

END-STATE PROPERTIES

1. The self-hosted pipeline exposes the declared top-level names of a program to
   the host without walking the reference compiler's syntax tree, covering every
   kind of top-level declaration the language admits that the reference
   extraction also counts.

2. A test compares that pipeline-derived information against the existing
   reference extraction and asserts they agree, comparing NAMES rather than
   positional indices.

3. The corpus that test runs over contains at least one instance of every
   declaration kind the comparison claims to cover. A kind absent from the
   corpus is not covered, and the tree does not claim otherwise.

4. Every derived set carries a non-vacuity assertion, so no guard passes by
   finding nothing to check.

5. The tree states plainly which parts of the reference extraction moved and
   which did not. Any returned value that still requires the reference syntax
   tree is named explicitly rather than implied away, and the migration is not
   described as complete when it is partial.

6. The count of migrated extractions is derived by a test from the driver's own
   contents rather than written as a literal in prose.

7. All stage sources still compile through the self-hosted pipeline with the
   byte-identity corpus unchanged in size and still passing.

8. No opcode is added and the bytecode version is unchanged.

9. Declaration kinds that were previously skipped because they once faulted the
   driver are still not admitted into the paths that faulted, and something
   checks that rather than leaving it to inspection.

10. Every guard added is demonstrated to fail when the property it checks is
    violated, using a mutation of the kind the real defect would produce, and
    any mutation whose result is believed is confirmed to have compiled first.

11. Guards that read only source text are not gated behind an off-by-default
    feature.

12. Test coverage is accounted for rather than sampled: the tree's records show
    that every test binary either ran or is named as not having run. A run
    lacking an exit status is not counted as a pass.

13. The persistent process channels reflect the increment, including any place
    where earlier recorded guidance proved inaccurate, with the correction
    recorded rather than the old text silently replaced.

14. Formatting, lint at deny-warnings, and the test suite are green for the
    feature sets continuous integration runs.
