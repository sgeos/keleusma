# BRIEF — an absorption prediction must carry the tree it was computed against

**Line**: V0.3.X native code generation. **Drafted**: 2026-09-12.

## The failure, from this morning

Absorption 59's brief predicted **zero conflicting files**. `merge-tree` computed **one**, and the
output was printed by the same command that wrote the brief.

**The prediction was not mistaken. It was stale.** Its `merge-tree` ran one iteration earlier against
a four-commit backlog; by the time it was filed the backlog was seven and both lines had rewritten
`REVERSE_PROMPT.md` in between.

**This is the session's recurring class arriving inside the discipline meant to catch it**: a figure
separated from the measurement that produced it. The bounds-transfer numbers, the WCMU unsoundness,
the "none acted on" claim — and now a prediction.

## Why a rule and not just care

The absorption protocol has four rules learned over 59 instances:

1. measure it ALONE;
2. record the prediction BEFORE merging;
3. verify the ownership boundary non-vacuously;
4. **(new) stamp the prediction with the backlog and HEAD it was computed against.**

Rules 1 to 3 live in the handoff's `DO THIS FIRST`. Rule 4 does not exist, and the failure it
addresses cost nothing this time only because the miss was harmless.

**A rule nobody can check is a rule that decays.** Every other figure on this line is pinned by
something that fails; a prediction is the one artefact whose whole purpose is to be compared and which
nothing compares.

## The wrong turns

1. **Do not write a fifth process document.** Rules 1 to 3 already have a home. A competing document
   is the duplication this package has unpicked three times, and the witness-registry note records
   what it costs.
2. **Do not retrofit 59 briefs.** The rule starts now; earlier briefs predate it and saying so is
   honest. A guard that demands compliance from documents written before the rule would be
   immediately disabled.
3. **Do not check every brief.** What matters is the NEXT prediction. A guard over the most recent
   absorption brief is always current and cannot rot into a list.
4. **Do not assert the numbers are right.** The guard cannot know the true backlog; it can only
   require that one was recorded. Claiming more would be a check that looks stronger than it is.

## What done looks like

The rule sits beside the three it joins; the most recent absorption brief carries the backlog count
and the commit its prediction was computed against; and something in the tree fails when the newest
one does not, saying that a prediction inherits the tree it was computed against.
