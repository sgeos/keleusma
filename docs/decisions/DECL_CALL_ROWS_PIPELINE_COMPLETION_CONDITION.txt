COMPLETION CONDITION — a pipeline analogue of one type-channel extraction

Ordering is NOT a completion criterion. Nothing below requires any particular
sequence, branch, commit shape, or process step. Judge only the end state of the
tree.

All of the following hold:

1. THE ANALOGUE EXISTS AND AGREES WITH THE REFERENCE.
   One of the type-channel extractions that previously had no pipeline analogue
   now has one, and a test compares the two over a corpus rather than over a
   single hand-written case. Agreement is asserted against the reference, not
   against an expectation written alongside the new code.

2. THE AGREEMENT IS NON-VACUOUS.
   The comparison fails if either side produces nothing. A row count is asserted
   to be non-zero, so an empty-versus-empty match cannot pass as agreement.

3. NO COMPARISON RESTS ON A SHARED NUMBERING THAT DOES NOT EXIST.
   If the two sides carry identifiers from different interners, the tree does not
   compare those identifiers. Either an id-free projection is compared, or the
   identity is carried in a form both sides agree on, and the choice is stated.

4. THE COUNT OF MOVED EXTRACTIONS IS STATED AS A MEASUREMENT.
   Wherever the tree describes the progress of the type checker's input, it gives
   the number moved out of the total, derived rather than recalled. No document
   describes the type checker as self-hosted without saying which half is meant:
   resolution or extraction.

5. IF THE SLICE PROVED INFEASIBLE, THAT IS RECORDED WITH ITS EVIDENCE.
   A recorded obstacle with the measurement that established it satisfies this
   condition. An abandoned attempt with no record does not.

6. EVERY NEW OR CHANGED GUARD HAS BEEN MADE TO FIRE.
   Each has an input that provokes it and an assertion on what it reports.

7. NO NEW OPCODE, AND NO BYTECODE_VERSION CHANGE.

8. THE SUITE IS GREEN ACROSS THE FEATURE SETS CONTINUOUS INTEGRATION BUILDS.
   Not one feature set. Every test file compiles under every feature set that
   builds it. The verdict comes from the test runner's own exit status read from
   its output, not from a filtered pipeline and not from a reported process exit
   code, and is corroborated by a second independent signal such as a count of
   completed test binaries. A truncated or killed run is not a pass.

9. DANGLING CITATIONS DID NOT GROW.
   No comment names a test, function, or symbol that does not exist, and the
   recorded backlog of excused citations did not grow.

10. THE CHANNELS DESCRIBE THIS STATE.
    The resume channels and the handoff describe what the tree now does, separate
    measurement from inference, and retain rather than delete any claim corrected
    during the work.
