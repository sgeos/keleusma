COMPLETION CONDITION — the float ladder's linkage claim (V0.3.X)

Ordering is NOT a completion criterion. The properties below may be reached in
any order, by any route. Judge the end state of the tree and the transcript, not
the sequence, the branch, or the process used to get there.

DONE when all of the following hold.

1. THE NARROW-WIDTH COST IS MEASURED ON THE BARE-METAL TARGET.
   An object is emitted for a program whose declared float width is the narrow
   one, for a target with no operating system, and its undefined symbols are
   read from the object. The count is reported.

2. THE COMPARISON IS AT EQUAL PROGRAM AND EQUAL TARGET.
   The narrow-width and wide-width figures come from the same program lowered
   for the same target, differing only in declared float width. A comparison
   across different programs or targets does not satisfy this.

3. THE RECORDED CLAIM IS RESOLVED IN WRITING.
   The document asserting that narrow float rungs buy native instructions states
   whether the measurement supports it. If it does not, the claim is corrected
   to what was measured rather than softened or left standing.

4. THE UNMEASURABLE HALF IS SEPARATED FROM THE MEASURED HALF.
   The record states which rungs the measurement covers and which it does not,
   and does not let a measured rung carry an unmeasured one.

5. THE BLOCKER ON THE UNIMPLEMENTED RUNG IS STATED CORRECTLY.
   Wherever that rung is described as blocked, the reason given is one that
   currently holds. A reason that has expired is replaced or removed rather than
   left in place.

6. EVERY SYMBOL COUNT CARRIES ITS TARGET AND ITS WIDTH.
   No figure appears without both, since several are available and differ.

7. THE MEASUREMENT READS AN OBJECT.
   Any claim about compiler-runtime symbols is supported by reading emitted
   object code, not the intermediate representation.

8. NON-VACUITY IS ESTABLISHED.
   The evidence includes something that fails if no object was emitted or if the
   symbol reader returned nothing, so an absence of symbols is distinguishable
   from an absence of measurement.

9. NOTHING IS CLAIMED THAT WAS NOT RUN.
   Every count and pass/fail claim corresponds to a command whose output appears
   in the transcript. Carried figures are marked as carried.

10. NEW OR CHANGED TESTS SURVIVE ORDINARY PARALLELISM.
    Any test added or modified is observed passing under the harness's default
    threading, not only in isolation.

11. THE PACKAGE IS GREEN, OR THE RED IS OWNED AND EXPLAINED.
    The native_codegen suite passes, or each failure is named with its cause and
    with a statement of whether the cause belongs to this package.

NOT completion criteria: which branch anything sits on, whether work is
committed, how many commits were made, the order of the eleven properties above,
or whether any other goal in the same session advanced.
