# Audit of the Shared-Slot Extension, 2026-11-08

> **Navigation**: [Shared slots](./README.md) | [Increment B2](../region_core/README.md)

A fresh context audited the plan-aware checker adversarially on 2026-11-08, given the sources and
increment B2's README, not the author's conclusions. It found no counterexample to the soundness
theorem or the generalisation theorem. Its exhaustive search, described in the README, accepted
more than half a million module and plan pairs with no divergence, and found 302 divergences when
the same search used B2's checker under the same plans, which shows the search detects one. Its
findings concerned coverage, the controls and the scan, and each was repaired or disclosed. The
repairs were checked by execution.

## Findings and repairs

| finding | standing | repair |
|---|---|---|
| The plan-aware checker requires both arms of a conditional to leave the same stack, so the commonest arm group, choosing between two composites and using the one chosen, is rejected, and the README claimed arm groups were covered | confirmed by execution | the join checker `ArmShape`, with its soundness theorem `reuse_sound_arm` and the proof that it accepts everything the earlier checkers accept, and the control `choose`, which only the join checker accepts and which agrees |
| The arm control could be weakened to use one site in both arms without the script noticing, since its slot check did not show two sites writing | confirmed by execution | `arms_one_slot` and `choose_agrees` now check the sites of the allocated regions, and the claims are pinned |
| The scan missed the singular `warning` attribute | confirmed by execution | the singular spelling and `Redirect` are refused, in all four scripts |
| The README cited a divergence proved for a plan textually equal to `Pshare` but not proved equal | confirmed by reading | `co_live_diverges` proves the divergence under `Pshare` itself |

## Attacks that failed

- An exhaustive search over short instruction words in loops, arms and with carried handles,
  under plans where three sites share a slot, where two share and a third has its own slot, and
  where a shared site meets an unplanned one.
- Hand-built cases with handles carried across iterations, `Dup`, `Drop` on an empty stack, and
  a site the plan leaves unplanned.
- The conflict rule when an allocation's site is unplanned while another site has a slot of the
  same number, which is sound because bump cells and slots never overlap.
- A mechanical comparison of the derived simulation with B2's, which differs only at the cases
  the README names.
- Hidden reliance on injectivity, which the shared lemmas do not capture.

The join checker was added after this audit. Its soundness rests on the checked theorem, its
controls and its pins.
