# Audit of the Part I Mechanisation, 2026-11-07

> **Navigation**: [The mechanisation](./README.md) | [The prose proof](../../COMPOSITE_REGION_REUSE_PROOF.md)

Two fresh contexts audited the mechanisation adversarially on 2026-11-07. Each was given the
sources and the prose, not the author's conclusions. One audited the fidelity of the statements
to Part I, and the other audited the model and the checker. Neither found a theorem that is
unsound. Both found the claims of the first draft stronger than the statements, and the second
found the checker able to pass planted defects. Every finding below was repaired or disclosed
before the merge. The checker and control repairs were checked by execution, and the
documentation repairs by reading against the statements. A delta check by a third fresh
context then found every repair present, and four small inaccuracies of the repairs
themselves, which are corrected.

## Attacks that failed

The auditors report trying the following without finding a defect.

- An unsound divergence hidden in `read`, `exec`, `read_corr` or `guards_hold`. A slot
  overwritten within an epoch does diverge, and stale reads fail identically in both regimes.
- A weakening of `sound` through a plan-dependent machine function or unequal run lengths. The
  machine function is shared and both runs stop together.
- A site executing twice that `once_per_epoch` misses. The case of two equal sites covers it.
- An inconsistency among the flow hypotheses. `F_nest` with `F_after`, `F_alloc` with
  `F_alive` and `F_exh`, and `F_fresh` with `F_prov` are jointly satisfiable by a run with reuse
  and reads.
- Breaking the comparison method through the machine function. Region indices are provenance,
  so a plan is address-free by construction.
- The two examples after Theorem C, which give footprint five against twenty and ten against
  five.
- `B_subadditive` and `B_mono`, which are sound.
- An early-exit loop in the bound, which fits as an iteration taking an empty arm.
- Environment storage in the excused set of Lemma 3, which stays sound because every read
  passes through an operand.
- A hidden axiom, which `Print Assumptions` and the `rocqchk` summary both exclude.
