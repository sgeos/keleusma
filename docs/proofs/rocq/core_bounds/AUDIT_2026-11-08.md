# Audit of Increment A, 2026-11-08

> **Navigation**: [Increment A](./README.md) | [Increment B1](../region_reuse/README.md)

Two fresh contexts audited increment A adversarially on 2026-11-08, each given the sources and
the cited specifications, not the author's conclusions. One audited the semantics and the
theorem statements, and the other audited the checker, the controls and the checking script.
Neither found a theorem that is unsound or vacuous, and the second ran six adversarial module
shapes without finding a run that exceeds either figure. Both found model gaps and overstated
claims, and the second found the checking script unable to detect a weakened statement. Each
finding below was repaired or disclosed. The repairs to the semantics, the checker, the controls
and the script were checked by execution, and the documentation repairs by reading against the
sources.

A delta check by a third fresh context then found ten repairs closed and three closed in
substance with a new inaccuracy each. The loop control's figure was described without the
reset it includes, the checker's growth was claimed linear while a body containing a
conditional grows quadratically, and a `warnings` attribute still silenced the no-warning rule.
It also showed that the pins do not protect definitions such as `stream_segs`. Each is
corrected or disclosed, and the attribute is refused on re-run.

## Attacks that failed

The auditors report trying the following without finding a defect.

- Segment measurement and `join`, including the junction across a reset and the trailing open
  segment, which `stream_bounded` covers.
- Hiding a case through fuel exhaustion. The headline theorems assert the run returns a result
  on the checker's fuel, and `fn_never_yields` quantifies over every fuel.
- A vacuous premise. The only premise is acceptance, which `Controls.ex_accepted` meets.
- Productivity, recursion, forward calls and calls of functions that do not exist, all rejected
  as the rules require.
- Host generality. A function of the outputs so far realises any sequence of replies, so the
  theorems cover nondeterministic hosts as well.
- Six adversarial module shapes, nested loops with yields and allocations, arms with different
  yield counts, a yielding call inside a loop, calls inside both arms under two hosts,
  zero-iteration loops around calls and yields, and a conditional yield inside a loop. No run
  exceeded either figure.
- Planted defects evading the word scan, a guard unset split across lines, a top-level variable
  of type falsehood under silenced warnings, and an unlisted lemma using the classical axiom,
  each refused by the `rocqchk` summary.
