2. Read the current resume section and guarded state table in
   [the archive](./v0.3.0.md). Measure its stamp with

   gates are stale for subsequent changes, so `UNVERIFIED` and exit one are

   unexpected changed input. Do not rerun full gates solely to clear staleness.
4. Fetch upstream and measure `git rev-list --count HEAD..origin/v0.2.3`.
   Absorb any backlog before relying on corpus figures. Read the archive's
   done-list, treating entries marked superseded as historical.
