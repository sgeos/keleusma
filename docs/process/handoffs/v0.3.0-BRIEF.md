# V0.3.X resume brief

The native backend lives in the detached `native_codegen/` package. Its canonical
worktree is `keleusma-worktrees/arena-composites` on `v0.3.0`. Root workspace
checks and remote continuous integration do not build this package.

## Resume

1. Read Appendix B before tracked edits.
2. Read the current resume section and guarded state table in
   [the archive](./v0.3.0.md). Measure its stamp with
   `git rev-list --count <stamp>..HEAD` and run its ancestry checks.
   Ancestry does not establish currency of capability claims.
3. Run `tools/gate-status.sh` from `native_codegen/`. Receipt-only changes can
   produce `UNVERIFIED` and exit one. Inspect the named inputs and targeted
   verification before deciding whether full gates need repeating.
   Investigate any recorded failure or malformed provenance.
4. Fetch upstream and measure `git rev-list --count HEAD..origin/v0.2.3`.
   Absorb any backlog before relying on corpus figures. Read the archive's
   done-list, treating entries marked superseded as historical.

## Constraints and verification

- Root `src/` and `tests/` are read-only to this line.
- Add no opcodes. Change no bytecode version without operator authorization.
- Publication remains held. Compare native results against the virtual machine.
- Commit once per prompt. Only feature branches may commit on red.
- Preserve the upstream current block and existing native reports when appending
  to the shared reverse prompt.
- Version integration requires green remote checks and relevant native checks.
  Full gates are required before publication or merging into `main`, under the
  [operator policy](../GATE_POLICY.md).
