## Standing facts worth not rediscovering

- **The full gate is ~2h33m and is repetition-bound, not contention-bound.** Measured 2026-08-09:
  `selfhost_codegen` is 1008 s standalone at 4.85 of 10 cores, and runs about four times across the
  feature matrix. Raising test parallelism buys nothing.
- **Reap orphans path-scoped**: `pkill -f "$PWD/target/debug/deps"`. Unscoped kills every worktree.
- **`tests/perf_canary.rs` is a tripwire, not a benchmark.** If it fires, rule out concurrent load
  and re-run alone before profiling, and profile before touching the ceiling.
- A gate result is valid only for the tip it ran against.

## Open decisions held by the operator

- ~~`GIT_STRATEGY.md` versus `merge-to-trunk.sh`.~~ **RESOLVED 2026-08-09.** The document was right
  and the script is the outlier. More importantly it exposed a defect in my own section 0: I had
  prescribed rebase-then-`--ff-only` for `v0.3.0`, which silently gives up the invariant `--no-ff`
  exists for. **`git rebase` drops merge commits**, so a bubble on a rebased line is destroyed by
  the next sync and its red work-in-progress lands on the spine; a bare `--ff-only` does the same
  by a different route. **A rebased line lands feature branches as one green commit (squash).**
  `merge-to-trunk.sh` is correct only when every commit on the branch is already green.
- **Trimming the gate's feature matrix.** The heavy self-host suites are insensitive to `signatures`
  and `shell`, so running them under those configurations is near-zero information for roughly
  34 minutes. Not done unilaterally: it weakens verification, and this project has been bitten by
  exactly that kind of "probably safe" reasoning.
- **Publication remains held.** Nothing is published.

## Method rules this arc paid for

- **A control executes a test's precondition** — that the predicate measures what you think it does.
  It runs in one direction only, so a **must-fire case** (defect present, check must report) and a
  **must-not-fire case** (defect absent, check must stay quiet) are both required. All three controls
  I ran on 2026-08-08 were must-fire cases and I recorded them as if they closed the question.
- **Executed beats reasoned, and an executed claim is only as good as its unexecuted preconditions.**
  A measured 3.7× speedup this arc came from a build with a live bug in it.
- **Rehearse a history rewrite on throwaway refs.** Two consecutive wrong rebase ranges of mine were
  caught that way.
