accumulated here, to be answered when convenient. Each entry says what this

## Open

9. **The rest of the corpus toward static kinds.** Twelve corpus coroutines
   still need a run-time kind, mostly for an operand that may hold `Unit` or a
   value after `Reset`. Removing that would need the language or the verifier
   to rule the ambiguity out. Is it worth pursuing before V0.4.0?
   The operator asked on 2026-10-28 for an explanation before answering. It
   was given in session.
19. **A self-hosted native compiler.** Added 2026-10-28 from the operator's
    answer to question 18, which says native code generation ideally wants to
    be able to use a self-hosted native compiler. Two readings are possible.
    Either native code generation should consume the self-hosted compiler's
    output, which is byte-identical to the reference's today, or the
    self-hosted compiler should itself be compiled to native code and used as
    the compiler. Which is meant, and is it part of V0.4.0? This line assumes
    meanwhile that it is not a V0.4.0 gate condition.

   This line reads it as follows, and the reading is to be confirmed. The option letters refer to [`ORDER_6_DECISION_OPTIONS.md`](../../decisions/ORDER_6_DECISION_OPTIONS.md).
